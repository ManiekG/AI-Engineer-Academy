# Miesiąc 1 — Python, Git, dane i API

Cel: opanować praktyczny Python potrzebny AI/LLM Engineerowi oraz zbudować pierwszy kompletny projekt — `Document Analyzer API`.

## Zakres

- Python praktyczny
- kolekcje i funkcje
- moduły i OOP
- dataclasses i typing
- pliki TXT / CSV / JSON
- wyjątki i logging
- NumPy i Pandas
- HTTP / REST
- FastAPI i Pydantic
- pytest
- Git
- Docker i Docker Compose

## Katalogi

- `exercises/` — codzienne ćwiczenia i mini-projekty
- `document-analyzer/` — projekt końcowy miesiąca

## Projekt końcowy

`Document Analyzer API` powinien:

- przyjmować pliki TXT / CSV / JSON,
- analizować ich zawartość,
- zwracać wynik w JSON,
- walidować dane wejściowe,
- obsługiwać błędy,
- posiadać testy,
- prowadzić logi,
- działać w Dockerze.

Szczegółowy plan 30 dni i status realizacji są w głównym pliku [`../m.md`](../m.md).
