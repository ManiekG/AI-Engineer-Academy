# Miesiąc 1 — Python

Cel: opanować praktyczny Python potrzebny do budowania narzędzi AI oraz stworzyć `document-analyzer`.

## Katalogi

- `exercises/` — codzienne ćwiczenia i rozwiązania
- `document-analyzer/` — projekt końcowy miesiąca

Kryterium ukończenia: narzędzie CLI analizuje co najmniej TXT, PDF i DOCX, zapisuje raport JSON/Markdown oraz ma testy kluczowych funkcji.
