# Dzień 25 — Git: podstawy

1. Utwórz plik `notes.md` z trzema rzeczami, których nauczyłeś się w miesiącu 1.
2. Sprawdź zmiany przez `git status` oraz `git diff`.
3. Dodaj plik przez `git add notes.md` i wykonaj opisowy commit.
4. Obejrzyj historię: `git log --oneline --decorate -5`.

Wynik: commit z jedną, logiczną zmianą i zrozumiałym komunikatem.
